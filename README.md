# Skills Claude Code

Ce dépôt regroupe les skills Claude Code installés localement, avec une courte description de leur utilité.

## Liste des skills

### [banner-design](./banner-design)
Conception de bannières pour réseaux sociaux, publicités, héros de site web et supports imprimés. Propose plusieurs directions artistiques (minimaliste, dégradé, néon, glassmorphism, etc.) avec visuels générés par IA.

### [brand](./brand)
Gestion de l'identité de marque : voix, identité visuelle, frameworks de messages, cohérence et organisation des assets. Utile pour du contenu de marque, un guide de style ou un audit de conformité à la marque.

### [caveman](./caveman)
Mode de communication ultra-compressé qui réduit les tokens de sortie d'environ 65 % en gardant l'exactitude technique. Plusieurs niveaux d'intensité disponibles (lite, full, ultra...).

### [design](./design)
Skill de design complet et unifié : identité de marque, tokens de design, style UI, génération de logos (55 styles), programme d'identité corporate, présentations HTML, bannières, icônes, visuels sociaux.

### [design-system](./design-system)
Architecture de tokens de design (primitif → sémantique → composant), variables CSS, échelles de typographie/espacement, spécifications de composants et génération de slides cohérentes avec la marque.

### [impeccable](./impeccable)
Skill avancé pour concevoir, refondre, auditer et polir des interfaces frontend (sites, dashboards, produits UI). Couvre l'UX, la hiérarchie visuelle, l'accessibilité, les animations, la typographie et bien plus.

### [slides](./slides)
Création de présentations HTML stratégiques avec graphiques Chart.js, tokens de design, mises en page responsives et formules de copywriting pour des slides percutantes.

### [ui-styling](./ui-styling)
Création d'interfaces belles et accessibles avec shadcn/ui (Radix UI + Tailwind), Tailwind CSS et des designs visuels basés sur canvas. Utile pour composants accessibles, thèmes, dark mode, etc.

### [ui-ux-pro-max](./ui-ux-pro-max)
Base de connaissances UI/UX consultable localement : styles, palettes produit, associations de polices, guidelines UX, icônes, presets d'animation GSAP, types de graphiques et stacks technologiques.
